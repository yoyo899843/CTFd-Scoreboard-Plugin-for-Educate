# CTFd Scoreboard Plugin for Educate

Author: yoyo899843

### This is a scoreboard that category students into school and classes

## Feature

You can filter users by the "School" and "Class".

![alt text](image.png)

You can import lists from csv, there is a download template.

![alt text](image-1.png)

## How to Install

In the CTFd dir

```
cd CTFd/plugins/
git clone https://github.com/yoyo899843/CTFd-Scoreboard-Plugin-for-Educate.git
cd ../../
sudo docker compose up --build -d
```
